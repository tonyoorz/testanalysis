## 📄 逐模块解析

### 1. `agent.py` — Agent 核心类

```python
import os
from openai import OpenAI

class Agent:
    def __init__(self, api_key=None, model="gpt-4o-mini"):
        # 创建 OpenAI 客户端
        # api_key 优先用传入的，否则读环境变量 OPENAI_API_KEY
        self.client = OpenAI(api_key=api_key or os.getenv("OPENAI_API_KEY"))
        
        # 使用轻量级模型，省钱速度快
        self.model = model
        
        # 对话历史 — 这是 Agent 有记忆的关键
        self.history = []
```

**设计原理：**
- `history` 列表存储所有对话上下文
- 每次对话都把**用户消息 + 助手回复**都存进去
- 发送给 API 时带上完整历史，模型就能"记住"之前说了什么

---

### 2. `chat()` 方法 — 核心逻辑

```python
def chat(self, message):
    # Step 1: 把用户输入加入历史
    self.history.append({"role": "user", "content": message})

    # Step 2: 调用 OpenAI API
    # 把完整对话历史发过去，模型基于上下文生成回复
    response = self.client.chat.completions.create(
        model=self.model,
        messages=self.history  # ⭐ 关键：带着上下文
    )

    # Step 3: 取出回复
    reply = response.choices[0].message.content
    
    # Step 4: 把助手回复也加入历史（这样下次对话模型就知道自己说过什么）
    self.history.append({"role": "assistant", "content": reply})
    
    return reply
```

**设计原理：**
- **上下文学习**：通过 `messages=self.history` 让模型"记住"对话历史
- **双向存储**：用户说一次、助手回一次，都存进去，下次请求模型就知道完整上下文

---

### 3. `reset()` 方法 — 清空记忆

```python
def reset(self):
    self.history = []
```

**设计原理：**
- 开始新对话时清空历史
- 避免历史干扰新话题

### 4. `main.py` — 程序入口

```python
import os

from agent import Agent

# 加载 .env 文件中的环境变量
load_dotenv()

    # 从环境变量读取 API Key

    if not api_key:
```
