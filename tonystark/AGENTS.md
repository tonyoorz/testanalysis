# TonyStark Agent Playbook

This vault is an agent-maintained knowledge base for AI-tool conversations.

## Mission
- Turn raw dialogues from tools like Trae, Claude Code, Kimi, and future coding agents into durable Obsidian notes.
- Maintain a compounding wiki instead of re-summarizing raw logs from scratch every time.

## Operating Rules
- Raw logs are sources of truth and remain unchanged.
- Summaries must cite source paths.
- If a tool only exposes partial logs, create an inventory note and a clear caveat.
- Prefer appending to existing tool and synthesis notes when the schema already covers the new material.

## Required Outputs
- Source inventory
- Session notes
- Tool notes
- Cross-session synthesis

## Preferred Linking
- Session note -> tool note
- Session note -> relevant topic notes
- Synthesis note -> representative sessions
